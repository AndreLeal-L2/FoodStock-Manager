Como usar a lista

A tua lista, organizada por categoria. Quantidades e alternativas por decidir ficam em aberto.

Marca os itens no carrinho e usa Finalizar compras para confirmar quantidades, preços, loja e data. Só depois de confirmares entram no stock e nos gastos.

Registar uma compra

Cada linha do talão é uma compra. O estoque é atualizado automaticamente.

Se compraste 2 embalagens de 500 g, regista 1 kg e o valor total das duas embalagens.

Histórico de compras

Quanto custa, de verdade?

Preço por unidade: a última compra comparada com a anterior. Melhores preços de todo o histórico, independentemente do ano selecionado.

Uma descida é uma oportunidade observada, não uma previsão de preços atuais. Compara o mesmo produto e a mesma qualidade.

Ligação à API local

Podes registar dados com a API desligada. A aplicação tenta enviar as alterações ao abrir, ao voltar a este separador e a cada 15 segundos enquanto está visível.

No Mac, podes usar http://localhost:8080. No telemóvel, usa um endereço HTTPS que chegue à API do Mac. O navegador pode pedir autorização de acesso local; consulta o README se bloquear a ligação.

Os teus dados

Moeda: EUR (€). A cópia deste navegador inclui alimentos, compras, lista e alterações ainda por enviar. Exporta um backup antes de limpar os dados do site ou mudar de dispositivo.

A exportação funciona sem API. Esta versão ainda não importa o ficheiro JSON nem permite editar ou apagar compras.
